直接使用原“电力小分队 · 资源中心”的同一个 GitHub 令牌。

令牌需授权目标仓库，Contents 权限为 Read and write。 令牌仅保存在当前页面内存中，不写入仓库或浏览器存储。

两个页面共用同一个令牌，但不会自动共享登录状态。 刷新或关闭页面后，需要重新输入。请勿将令牌写进 HTML。

管理收藏标签

只有管理员可修改。一个资源可以属于多个标签。

删除标签只取消分类关联，不会删除资源。 没有标签的资源仍在“全部收藏”中显示。

资源库设置

接口用于管理员收录时获取真实标题、摘要和封面。 未配置时仍可手动收录和显示图文卡片。 此地址会公开保存，不能包含私密 API 密钥。

清理仅针对管理员人工确认失效的资源。 登录限制、验证码、网络超时和 HTTP 403，不能直接认定为内容删除。
