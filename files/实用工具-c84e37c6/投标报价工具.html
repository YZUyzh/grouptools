1. 区间平均价浮动法

  • M ≤ 5：不剔除极值。
  • 5 < M ≤ 10：剔除最高 1 个、最低 1 个。
  • 10 < M ≤ 20：剔除最高 2 个、最低 1 个。
  • 20 < M ≤ 30：剔除最高 3 个、最低 2 个。
  • M > 30：剔除最高 4 个、最低 3 个。

剩余样本平均价为 A1；有效样本满足 A1 × (1 + W1) < 报价 < A1 × (1 + W2)。区间内人数为零时，回退到全部剩余样本，不重新纳入已剔除极值者。有效样本均价为 A2；基准价 = A2 × (1 − C)。

默认 n1 = 1，n2 = 0.5，W1 = −15%，W2 = 10%，C = 0%。

2. 简单算术平均值法

全部勾选的详评投标人报价平均值即基准价；不剔除、不筛区间、不使用 C。默认 n1 = 1，n2 = 1。

共同计分公式

价格分 = max(0, 100 − 100 × n × |报价 − 基准价| / 基准价)
报价 ≥ 基准价时 n = n1，否则 n = n2。加权分 = 价格分 × 权重 / 100。

同价、排名与解释边界

原条款未明确极值边界同价如何剔除。本工具按“价格升序，同价按列表顺序”固定剔除人数，边界同价时显示警告。正式评审应以招标文件补充条款或评审方解释为准。价格分并列采用竞赛排名（例如 1、1、3），按未四舍五入分数比较，并使用极小数值容差。

历史与安全

报价记录仅自动保存在本浏览器 localStorage；清理浏览器或换设备可能丢失。JSON 导出为项目全部轮次，不含通行证、GitHub 令牌。GitHub 仅用于发布通行证的加盐 PBKDF2 校验记录；公开校验记录仍有离线猜测风险，请使用高强度随机通行证。管理员令牌只存页面内存，关闭页面或退出管理员后消失。

初评勾选人数必须有完整、正数报价；空值或非正数会停止本轮评分，不悄悄删除样本。未勾选的报价不影响计算。

通行证管理

使用 GitHub Personal Access Token 读写通行证配置。不是 SSH 密钥。

仅将通行证校验记录写入仓库，不上传报价。建议使用专门的公开仓库；令牌需授权目标仓库，Contents 权限为 Read and write。纯静态方案不构成服务端鉴权。

仓库设置可先保存，再连接管理员。通行证配置必须在公开仓库中，以便访问者在无令牌时读取。给其他用户使用前，应把代码中的 DEFAULT_REPO 改成你的正式仓库设置。
