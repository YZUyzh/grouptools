评审办法附表三：价格评分标准

1. 区间平均价浮动法

初评合格人数 M先剔除最低数量先剔除最高数量
M ≤ 500
5 < M ≤ 1011
10 < M ≤ 2012（最高、次高）
20 < M ≤ 3023（最高、次高、第三高）
M > 3034

先按上表处理极值，再计算剩余 X 个投标人的评标价算术平均值 A1。M ≤ 5 时，X = M。

有效投标人满足：A1 × (1 + W1) < 评标价 < A1 × (1 + W2)，两端不含本数。区间内人数为 0 时，全部剩余 X 个投标人为有效投标人；已剔除极值者不重新纳入。

有效投标人算术平均值为 A2。基准价 = A2 × (1 − C)。

默认参数：n1=1、n2=0.5、W1=−0.15、W2=0.1、C=0；界面 W1/W2/C 按百分数填写，即 −15 / 10 / 0。

2. 简单算术平均值法

所有进入详评的投标人评标价算术平均值为基准价。不剔除极值、不筛选区间、不使用 C。默认参数：n1=1、n2=1。

共同评分公式

价格分 = max(0, 100 − 100 × n × |评标总价 − 基准价| / 基准价)
评标总价 ≥ 基准价时 n=n1；评标总价 < 基准价时 n=n2。
实际加权分 = 价格分 × 价格权重 / 100。

计分不使用界面显示的四舍五入值，内部使用完整计算值。价格排名不含技术、商务分；相同价格分采用竞赛排名，例如 1、1、3，使用极小数值容差。

限价是独立的资格设置

原评分条款没有规定超限处理，因此默认“仅提示”，不改变样本人数和评分。选择“超限不参与评审”后，严格大于限价者不计入 M、不计算价格分；等于限价仍可参与。策略候选始终不高于限价。正式使用应按招标文件确定超限规则。

同价极值与输入有效性

条款未明确极值边界同价处理。本工具按价格升序，同价按列表顺序，固定剔除指定数量，并在边界同价时提示。正式评审需核实招标文件补充规定。

参与者存在空报价或非正数报价时，本轮暂停计分，不默默删除样本。未勾选者不参与计算。

策略、安全与历史

策略仅支持我方独立报价分析，竞争对手报价为假设。对手共同浮动仅为压力测试，不代表概率或最坏情况。成本、利润、限价、异常低价审查及履约风险应另行核实。

本地自动保存使用 localStorage，报价不加密；导出 JSON 不含通行证、GitHub 令牌。不同设备需手动导入 JSON。通行证至少6位，但推荐随机长通行证。公开校验记录存在离线猜测风险；静态通行证不是后端鉴权，无法强制退出已登录页面。
