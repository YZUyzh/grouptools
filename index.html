管理员登录

连接仓库，管理分类与资源。

令牌需授权目标仓库，Contents 权限为 Read and write。令牌仅保存在当前页面内存中，不写入仓库或浏览器存储。

新增资源

点击资源名称后，直接打开对应链接。

修改分类仅调整入口归属。实际移动文件，请使用移动按钮或拖动。

上传文件

普通资料可多选；HTML 工具建议上传完整文件夹。

文件将公开发布。不要上传密码、密钥或私密资料；只上传可信的 HTML 工具。

磁盘子文件夹不会自动变成页面分类。需要可点击的分类文件夹，请使用“新建子分类”。

尚未选择文件

不设每批数量上限。单文件仍受 GitHub 普通文件约 100 MiB 上限约束，也受网络和浏览器内存限制。

移动资源

文件与资源链接在同一次提交中更新。

目标有同名文件时停止，不覆盖。已在目标位置的文件会跳过。其他网页中的旧链接不会自动改写。

分类排序

调整同级分类的显示顺序，不改变分类层级和文件路径。

可以切换不同父分类继续调整，最后统一保存。保存后左侧目录和分类文件夹使用相同顺序，访客在部署更新后可见。
